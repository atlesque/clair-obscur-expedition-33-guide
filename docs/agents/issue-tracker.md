# Issue tracker: GitHub

Issues and specifications for this project live in GitHub Issues at https://github.com/atlesque/clair-obscur-expedition-33-guide.

Use the GitHub CLI, with the repository specified explicitly for issue and label operations. Follow the project's RTK command convention. For multiline issue bodies and comments, write the exact Markdown to a file and use `--body-file`.

When a skill says to publish to the issue tracker, create an issue in this repository, checking first for an existing issue for the same work. Read issues with their bodies, labels, and relevant comments. Apply the label mapping from the triage-label document. Do not interpret publishing a specification as authorization to start its implementation.

PRs as a request surface: no.
