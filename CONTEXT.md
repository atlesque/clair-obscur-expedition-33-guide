# Expedition Leveling Guide

The language of a spoiler-conscious leveling companion for Clair Obscur: Expedition 33.

## Language

**Playthrough**:
A named, independent record of a player's journey, including the characters they track and each character's progression. Different people can keep separate playthroughs.
_Avoid_: Account, session, user profile

**Tracked character**:
A character the player has added to a particular playthrough for leveling guidance.

**Removed character**:
A previously tracked character hidden from the party view whose recorded progression is retained for restoration within the same playthrough.

**Recommended build**:
The guide's default progression plan for a character's attributes and skills, intended for a forgiving first playthrough with a balance of survivability and reliable damage.
_Avoid_: Optimal build, best build

**Level-up**:
An increase in one character's in-game level, reported by the player to obtain progression guidance.

**Attribute allocation**:
The distribution of a character's invested attribute points.

**Pending recommendation**:
Suggested attribute or skill spending that the player has not yet confirmed applying in-game. It is advice, not a record of spent points.

**Unlocked skill**:
A skill the character has acquired and can choose to equip. An unlocked skill is not necessarily equipped.

**Skill loadout**:
The set of unlocked skills selected for a character to use in combat.
_Avoid_: Unlocked skills, skill tree

**Character reveal**:
The deliberate disclosure of a previously hidden character's identity after the player's explicit consent. Revealing a character does not itself add that character to a playthrough.
